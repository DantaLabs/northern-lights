# Freeze Wave 4.2, 4.3 and 5 until the demo

Wave 4.2 content placement, Wave 4.3 workflows, Wave 5 production recovery and the official Workiva MCP adapter are paused until the KPMG demo on 2 November 2026. Their live gates (Copilot file handoff, signed operator policies, backup and restore, MCP gateway entitlement) blocked progress for eight days and do not change what the demo audience sees. Demo tools sit behind `NL_DEMO_PIPELINE=true` so the frozen code and its tests stay untouched; work resumes from the existing branches after the demo.
