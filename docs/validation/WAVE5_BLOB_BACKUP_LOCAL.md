# Wave 5 private Blob backup transport (bounded local pass)

`internal/assurance/azure_backup.go` is an opt-in transport, not wired into the MCP server or Container App. It accepts a locally created signed `database.sqlite` / `manifest.json` envelope. A configured tenant and environment bind both private Blob names and object metadata. Upload verifies local signature, SQLite integrity, schema markers, audit/checkpoint and row counts, then creates the database and manifest using `If-None-Match: *`. It checks each upload by exact digest, byte length, metadata and returned ETag. An existing object, failed readback or ambiguous timeout fails closed; no overwrite, delete, or adoption occurs. A database-only partial upload remains an orphan requiring operator attention.

Restore chooses an explicit envelope ID and independent rollback minimum (creation time, audit sequence or pinned database hash). It downloads manifest and database into a private empty local temporary directory, validates object metadata and digest, then invokes `RestoreBackup` to verify signature, SQLite integrity, schema, audit chain, checkpoint and row counts before installing into an empty local destination. `Ready` means local database verification only; it is NOT permission to serve writes or evidence of external fence join. No SQL runs on Azure Files.

Prerequisites NOT satisfied here: authenticated production-wide writer drain including every materializing path; on-demand coordinated backup and policy for checkpoint/high-water authority and backup selection; sealed-object access policy (private container, identity/RBAC, immutability/retention and shared-key/public-access restrictions); startup scan/join/quarantine of transfer fences through the backup high-water mark; crash/rollback rehearsal against a disposable Azure revision, restored SQLite copy and live endpoint; independent verification of audit coverage and missing terminal-row caveats; operational RPO/RTO validation. Existing canonical Container App remains unchanged. No live Azure request, deployment, commit or push was made in this pass.
